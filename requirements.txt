# --- TLS for the Twisted SSL endpoint (live.ctraderapi.com:5035) ----------
# ctrader-open-api hard-pins pyOpenSSL==24.1.0, so that pin drives this stack:
# pinning a newer pyOpenSSL here makes the file uninstallable in one pass
# (pip: ResolutionImpossible) and breaks the Railway build.
#
# pyOpenSSL 24.1.0 requires cryptography<43, and that bound must be respected:
# an old pyOpenSSL against a modern cryptography aborts Twisted's TLS import
# with "AttributeError: module 'lib' has no attribute 'GEN_EMAIL'".
cryptography==42.0.8
# Without service-identity, Twisted does only rudimentary hostname verification.
